# Guildrun Demo 日本語化MOD

元配布ポスト： [Xのポストを見る](https://x.com/tomathinn_G/status/2078683987103690755)

## ダウンロード

### [Guildrun-Japanese-Mod.zipをダウンロード](https://github.com/tomate045/Guildrun-Japanese-Mod/releases/latest/download/Guildrun-Japanese-Mod.zip)

## 初めて導入する

1. ダウンロードしたZIPを展開します。「Guildrun日本語化MOD」フォルダーができます。
2. Steamライブラリの「Guildrun Demo」を右クリックします。
3. 「管理」→「ローカルファイルを閲覧」を押します。
4. 手順1の「Guildrun日本語化MOD」フォルダーを、手順3で開いたフォルダー（Guildrun.exeがある場所）へコピーします。
5. ゲームを終了した状態で、コピーしたフォルダーの中にある「Guildrun日本語化」を起動します。
6. 「翻訳データを取得して日本語化」を押します。
7. 「日本語化が完了しました」と表示されたらゲームを起動し、「Settings」→「Language」→「日本語（MOD）」を選びます。

フォルダーの中身はそのままにして、フォルダーごと移動してください。

### 以前の単一EXE版を使っていた場合

ゲームフォルダー直下に置いていた古い「Guildrun日本語化」と`data`フォルダーは削除してください。
必要に応じてSteamの「ゲームファイルの整合性を確認」を行ってから、
上記の「Guildrun日本語化MOD」フォルダーを配置してください。
古いEXEは新しい更新方式に対応していないため、今後は起動しないでください。

## MODを更新する

「Guildrun日本語化」を起動して「更新を確認」を押すと、翻訳データの更新を確認できます。
「最新版を適用して日本語化」を押すと、更新の取得と日本語化をまとめて行います。

アプリ内部の更新を含む場合は、適用後に再起動の案内が表示されます。
その場合は一度画面を閉じ、もう一度起動して「既存ファイルで日本語化」を押してください。

まれにMOD本体の新版が案内されることがあります。その場合は、上のリンクから新しいZIPをダウンロードし、
ゲームフォルダー内の「Guildrun日本語化MOD」フォルダーを新しいものへ置き換えてください。

ゲーム本体のアップデートで問題が発生した場合は、ゲームファイルの整合性確認を行ったうえで、上記導入手順の手順5～7をもう一度行ってください。

### ゲーム起動時に更新を確認する（任意）

「Steam起動オプションをコピー」を押し、表示された案内どおりにSteamへ貼り付けると、
Guildrun Demoを起動した時にMODの更新も確認できます。

この確認では更新のダウンロードや日本語化は行いません。更新がある時だけ案内を表示します。
設定をやめる場合は、Steamに貼り付けた起動オプションを削除してください。

すでに別の起動オプションを設定している場合は内容が置き換わるため、貼り付ける前に元の内容を控えておいてください。
起動時にコマンドプロンプトが一瞬表示される場合があります。

## サイズ差異の警告が出た場合

ゲームの英語原文が対応時点から変わっていると、サイズ差異の警告が表示されます。

「はい」を押すと、そのまま日本語化データを生成・検証し、ゲームへ適用します。
「いいえ」を押した場合は何も変更しません。

警告が出た場合、ゲーム側の更新にMODがまだ対応できていない可能性があります。
この状態で日本語化を続けると、ゲーム側で追加・変更された文章が英語のままになったり、以前の内容のまま表示されたりする可能性があります。更新をお待ちください。

## 各ボタンについて

- **翻訳データを取得して日本語化**
  初回起動時に表示されます。GitHubから翻訳データとフォントを取得し、そのまま日本語化します。

- **更新を確認**  
  GitHubに接続し、翻訳データやフォントなどに更新があるか確認します。アプリ本体に新版がある場合も案内します。

- **最新版を適用して日本語化**  
  更新されたファイルをダウンロードし、そのまま日本語化を行います。

- **既存ファイルで日本語化**  
  すでにローカルに存在するデータを使って日本語化します。GitHubへの接続は行いません。

- **Steam起動オプションをコピー**
  Guildrun Demoの起動時に、MODの更新だけを確認するための設定をコピーします。設定はSteamへ自分で貼り付けます。

## 元に戻す

Steamで「Guildrun Demo」の「プロパティ」→「インストール済みファイル」→「ゲームファイルの整合性を確認」を行ってください。

「Guildrun日本語化MOD」フォルダーが残っていてもゲームには影響ありませんが、気になる場合はフォルダーごと削除してください。
