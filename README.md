# Guildrun Demo 日本語化MOD

Guildrun Demoの英語テキストを日本語化し、日本語表示用のフォントを導入する非公式MODです。

## ダウンロード

### [最新版のGuildrun日本語化.exeをダウンロード](https://raw.githubusercontent.com/tomate045/Guildrun-Japanese-Mod/updates/Guildrun%E6%97%A5%E6%9C%AC%E8%AA%9E%E5%8C%96.exe)

導入に必要なのはこのEXEだけです。ZIPやdataフォルダーを別にダウンロードする必要はありません。

> [!IMPORTANT]
> 以前の日本語化MODを導入済みの場合や、ゲーム本体がアップデートされた場合は、最初にSteamでゲームファイルの整合性を確認してください。

## 導入方法

1. Steamライブラリで「Guildrun Demo」を右クリックします。
2. 「管理」→「ローカルファイルを閲覧」を選び、ゲームフォルダーを開きます。
3. ダウンロードした「Guildrun日本語化」（種類：アプリケーション）を、`Guildrun.exe`と同じ場所へ移動します。
4. ゲームを終了した状態で「Guildrun日本語化」を起動し、「更新を確認」を押します。
5. 更新が見つかったら、「最新版を適用して日本語化」を押します。
6. 「日本語化が完了しました」と表示されたらゲームを起動し、「Settings」→「Language」→「日本語（MOD）」を選びます。

初回はGitHubから翻訳データとフォントを取得するため、インターネット接続が必要です。

## MODを更新する

ゲームフォルダーに置いた「Guildrun日本語化」を起動し、「更新を確認」を押してください。
更新がある場合は、EXE・翻訳データ・フォントなど、変更されたファイルだけを取得します。

「既存ファイルで日本語化」は、既に取得済みのデータだけで日本語化し直すボタンです。この操作ではGitHubへ接続しません。

## ゲーム本体がアップデートされた場合

1. Steamで「Guildrun Demo」の「プロパティ」を開きます。
2. 「インストール済みファイル」→「ゲームファイルの整合性を確認」を実行します。
3. 確認が完了したら「Guildrun日本語化」を起動し、「既存ファイルで日本語化」を押します。

英語原文ファイルのサイズが対応時点と異なる場合は警告が表示されます。未対応の更新である可能性があるため、内容を確認してから続行してください。

## 元に戻す

Steamで「Guildrun Demo」の「プロパティ」→「インストール済みファイル」→「ゲームファイルの整合性を確認」を実行してください。

## フォント

日本語表示にはNoto Sans JPを使用しています。ライセンスは[OFL.txt](https://github.com/tomate045/Guildrun-Japanese-Mod/blob/updates/OFL.txt)を参照してください。
