## 初めて導入する

1. Steamライブラリの「Guildrun Demo」を右クリックします。
2. 「管理」→「ローカルファイルを閲覧」を押します。
3. ダウンロードした「Guildrun日本語化」（種類：アプリケーション）を、手順2で開いたフォルダーへコピーします。
4. ゲームを終了した状態で「Guildrun日本語化」を起動します。
5. 「更新を確認」を押します。
6. 「更新があります」と表示されたら、「最新版を適用して日本語化」を押します。
7. 「日本語化が完了しました」と表示されたらゲームを起動し、「Settings」→「Language」→「日本語（MOD）」を選びます。

## MODを更新する

ゲーム本体のアップデートで問題が発生した場合は、ゲームファイルの整合性確認を行ったうえで、上記導入手順の手順4～7をもう一度行ってください。

## サイズ差異の警告が出た場合

ゲームの英語原文が対応時点から変わっていると、サイズ差異の警告が表示されます。

「はい」を押すと、そのまま日本語化データを生成・検証し、ゲームへ適用します。
「いいえ」を押した場合は何も変更しません。

警告が出た場合、ゲーム側の更新にMODがまだ対応できていない可能性があります。
この状態で日本語化を続けると、ゲーム側で追加・変更された文章が英語のままになったり、以前の内容のまま表示されたりする可能性があります。更新をお待ちください。

## 各ボタンについて

- **更新を確認**  
  GitHubに接続し、EXEや翻訳データ、フォントなどに更新があるか確認します。

- **最新版を適用して日本語化**  
  更新されたファイルをダウンロードし、そのまま日本語化を行います。

- **既存ファイルで日本語化**  
  すでにローカルに存在するデータを使って日本語化します。GitHubへの接続は行いません。

## 元に戻す

Steamで「Guildrun Demo」の「プロパティ」→「インストール済みファイル」→「ゲームファイルの整合性を確認」を行ってください。

「Guildrun日本語化」やdataフォルダーが残っていてもゲームには影響ありませんが、気になる場合はこちらも削除してください。
