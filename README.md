# Guildrun Demo 日本語化MOD

Guildrun Demoを日本語で遊ぶために、個人で作っている非公式MODです。
ゲーム内の文章を日本語化し、日本語表示用のフォントも一緒に導入します。

翻訳がおかしいところや、表示が崩れているところがあれば、教えてもらえると助かります。

## ダウンロード

### [Guildrun日本語化.exeをダウンロード](https://raw.githubusercontent.com/tomate045/Guildrun-Japanese-Mod/updates/Guildrun%E6%97%A5%E6%9C%AC%E8%AA%9E%E5%8C%96.exe)

新しく導入する場合も、MODを更新する場合も、使うのはこのファイルです。

## 導入方法

0. 以前に日本語化MODを導入したことがある場合や、ゲーム本体がアップデートされた後は、先にSteamで「Guildrun Demo」の「プロパティ」→「インストール済みファイル」→「ゲームファイルの整合性を確認」を行います。初めて導入する場合は、そのまま手順1へ進んでください。
1. Steamライブラリの「Guildrun Demo」を右クリックします。
2. 「管理」→「ローカルファイルを閲覧」を押して、ゲームのフォルダーを開きます。
3. ダウンロードした「Guildrun日本語化」（種類：アプリケーション）を、`Guildrun.exe`と同じ場所へ移動します。
4. ゲームを閉じた状態で「Guildrun日本語化」を起動します。
5. 「更新を確認」を押します。
6. 表示された内容に合わせて、次のどちらかを押します。
   - 「更新があります」と表示された場合：**「最新版を適用して日本語化」**
   - 「現在のファイルは最新版です」と表示された場合：**「既存ファイルで日本語化」**
7. 「日本語化が完了しました」と表示されたらゲームを起動し、「Settings」→「Language」→「日本語（MOD）」を選びます。

「更新を確認」を押すと、GitHubに接続してEXEや翻訳データ、フォントなどに更新がないか確認します。
初回は日本語化に必要なファイルを一式ダウンロードし、2回目以降は変更されたファイルだけを更新します。

## MODを更新する

ゲームのフォルダーに置いた「Guildrun日本語化」を起動し、「更新を確認」を押してください。
更新が見つかったら、「最新版を適用して日本語化」を押せば更新と日本語化をまとめて行います。

ゲーム本体がアップデートされた場合は、上の導入方法の手順0からやり直してください。

## サイズ差異の警告が出た場合

ゲームの英語原文が対応時点から変わっていると、サイズ差異の警告が表示されます。
この警告が出ても、「はい」を押せばそのまま生成と検証を行い、問題がなければ日本語化できます。

「いいえ」を押した場合は何も変更しません。
生成や検証に失敗した場合もゲームファイルは変更せず、適用中に問題が起きた場合は元のファイルへ戻します。

## 「既存ファイルで日本語化」について

すでにダウンロードしてある翻訳データを使って、もう一度日本語化するためのボタンです。
このボタンを押した場合はGitHubに接続しません。

## 元に戻す

アンインストーラーはありません。
Steamで「Guildrun Demo」の「プロパティ」→「インストール済みファイル」→「ゲームファイルの整合性を確認」を行えば、元の状態に戻せます。

## フォント

日本語表示にはNoto Sans JPを使っています。フォントのライセンスはこちらです： [OFL.txt](https://github.com/tomate045/Guildrun-Japanese-Mod/blob/updates/OFL.txt)
