# Guildrun Demo 日本語化MOD

Guildrun Demoを日本語で遊ぶために、個人で作っている非公式MODです。
ゲーム内の文章を日本語化し、日本語表示用のフォントも一緒に導入します。

翻訳がおかしいところや、表示が崩れているところがあれば、教えてもらえると助かります。

## ダウンロード

### [Guildrun日本語化.exeをダウンロード](https://raw.githubusercontent.com/tomate045/Guildrun-Japanese-Mod/updates/Guildrun%E6%97%A5%E6%9C%AC%E8%AA%9E%E5%8C%96.exe)

ダウンロードするのは、このファイル1つだけでOKです。

> [!IMPORTANT]
> 以前の日本語化MODを入れている場合や、ゲーム本体がアップデートされた後は、先にSteamで「ゲームファイルの整合性を確認」を行ってください。

## 導入方法

1. Steamライブラリの「Guildrun Demo」を右クリックして、「管理」→「ローカルファイルを閲覧」を押します。
2. ダウンロードした「Guildrun日本語化」（種類：アプリケーション）を、`Guildrun.exe`と同じ場所へ移動します。
3. ゲームを閉じた状態で「Guildrun日本語化」を起動し、「更新を確認」を押します。
4. 更新が見つかったら、「最新版を適用して日本語化」を押します。
5. 完了後にゲームを起動し、「Settings」→「Language」から「日本語（MOD）」を選びます。

最初の1回だけ、翻訳データとフォントをGitHubからダウンロードします。

## MODを更新する

ゲームフォルダーに置いた「Guildrun日本語化」を起動して、「更新を確認」を押してください。
更新があれば、必要なファイルだけダウンロードします。

「既存ファイルで日本語化」は、すでにダウンロードしてあるデータを使って、もう一度日本語化するためのボタンです。こちらはインターネットに接続しません。

## ゲーム本体がアップデートされた場合

ゲームが更新された後は、そのまま日本語化し直さず、先に以下の手順で元のファイルへ戻してください。

1. Steamで「Guildrun Demo」の「プロパティ」を開きます。
2. 「インストール済みファイル」→「ゲームファイルの整合性を確認」を押します。
3. 終わったら「Guildrun日本語化」を起動し、「更新を確認」してから日本語化します。

ゲーム側の変更にまだ対応できていない場合は、途中で警告が出ることがあります。その場合は、無理に進めず対応版を出すまでお待ちください。

## 元に戻す

アンインストーラーはありません。
Steamで「Guildrun Demo」の「プロパティ」→「インストール済みファイル」→「ゲームファイルの整合性を確認」を行えば、元の状態に戻せます。

## フォント

日本語表示にはNoto Sans JPを使っています。フォントのライセンスはこちらです： [OFL.txt](https://github.com/tomate045/Guildrun-Japanese-Mod/blob/updates/OFL.txt)
