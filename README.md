# Guildrun Demo 日本語化MOD

元配布ポスト： [Xのポストを見る](https://x.com/tomathinn_G/status/2078683987103690755)

## ダウンロード

### [Guildrun-Japanese-Mod.zipをダウンロード](https://github.com/tomate045/Guildrun-Japanese-Mod/releases/latest/download/Guildrun-Japanese-Mod.zip)

## 導入手順

1. ダウンロードしたZIPを展開します。「Guildrun-Japanese-Mod」フォルダが出来ます。
2. 「Guildrun-Japanese-Mod」を開くと **「Guildrun日本語化MOD」フォルダ** が入っています。
3. Steamライブラリの「Guildrun Demo」を右クリックします。
4. 「管理」→「ローカルファイルを閲覧」を押します。
5. 手順2の **「Guildrun日本語化MOD」フォルダ** を、手順4で開いたフォルダ（Guildrun.exeがある場所）へ **フォルダごと**移動します。
6. ゲームを終了した状態で、移動した **「Guildrun日本語化MOD」フォルダ** の中にある **「Guildrun日本語化」** を起動します。
7. **「翻訳データを取得して日本語化」** を押します。
8. 「日本語化が完了しました」と表示されたらゲームを起動し、「Settings」→「Language」→「日本語（MOD）」を選びます。

### 以前の単一EXE版を使っていた場合

ゲームフォルダ直下に置いていた古い「Guildrun日本語化」と`data`フォルダは削除してください。

### Google Driveからダウンロードした場合

手順1で生成されるフォルダ名が異なる場合がありますが、内部には同じく **「Guildrun日本語化MOD」フォルダ** が入っています。

## MODを更新する

「Guildrun日本語化」を起動し、 **「最新版で日本語化」** を押してください。
更新がある場合は、必要なファイルの取得と日本語化をまとめて行います。

日本語化アプリ自体に更新がある場合も、自動で再起動して残りの処理を続けます。

まれに、新しいZIPへの入れ替えが必要な更新が案内されることがあります。その場合は、上のリンクから新しいZIPをダウンロードし、
ゲームフォルダ内の「Guildrun日本語化MOD」フォルダを新しいものへ置き換えてください。

ゲーム本体のアップデートで問題が発生した場合は、ゲームファイルの整合性確認を行ったあと、
「最新版で日本語化」を押してください。「すでに最新版です」と表示された場合は、
「手元のデータで日本語化をやり直す」を押してください。

### ゲーム起動時に更新を確認する（任意）

Steamの起動オプション機能を使って、Guildrun Demoの起動時に
日本語化MODの更新を確認できるようにする機能です。

更新がある場合は、案内の「今すぐ更新して日本語化」を押すと、ゲームを強制終了して更新を行います。
設定をやめる場合は、Steamに貼り付けた起動オプションを削除してください。

起動時にコマンドプロンプトが一瞬表示される場合があります。

## サイズ差異の警告が出た場合

ゲームの英語原文が対応時点から変わっていると、サイズ差異の警告が表示されます。

「はい」を押すと、そのまま日本語化データを生成・検証し、ゲームへ適用します。
「いいえ」を押した場合は何も変更しません。

警告が出た場合、ゲーム側の更新にMODがまだ追従できていない可能性があります。
この状態でプレイすると、ゲーム側で追加・変更された文章が一部英語のままになったり、以前の内容のまま表示されたりする可能性があります。
申し訳ありませんが、更新をお待ちください。

## 各ボタンについて

- **翻訳データを取得して日本語化**
  初回起動時に表示されます。GitHubから翻訳データとフォントを取得し、そのまま日本語化します。

- **最新版で日本語化**
  更新を確認し、新しいデータがあれば取得して日本語化を行います。すでに最新版の場合は何も変更しません。

- **手元のデータで日本語化をやり直す**
  更新を確認せず、すでに保存されているデータで日本語化をやり直します。通常は使用しません。

- **ゲーム起動時にこのMODの更新があるか確認する**
  Guildrun Demoの起動時に、日本語化MODの更新を確認するための設定です。

## アンインストール

Steamで「Guildrun Demo」の「プロパティ」→「インストール済みファイル」→「ゲームファイルの整合性を確認」を行ってください。

「Guildrun日本語化MOD」フォルダが残っていてもゲームには影響ありませんが、気になる場合はフォルダごと削除してください。
ゲーム起動時に更新を確認する設定を行っていた場合は、起動オプションを削除してください。
